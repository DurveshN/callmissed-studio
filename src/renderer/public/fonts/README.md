# Bundled fonts

All fonts are from [google/fonts](https://github.com/google/fonts) at commit
`bd8f81ddb5c74d5c8897b36ad88b440266245103`, unmodified, under the SIL Open Font License 1.1
(each family's `OFL.txt` is next to its files). They are used for text editing and for matching
the typeface of detected text. Catalogue: `src/renderer/src/features/fonts/catalog.ts`.
